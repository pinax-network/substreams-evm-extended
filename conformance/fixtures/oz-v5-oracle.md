# Pinned OpenZeppelin source execution oracle

`oz-v5-oracle.bin-runtime` is the **hex text** of a 4,575-byte local harness
compiled with solc `0.8.20+commit.a1b79de6`, optimizer enabled, target `paris`,
metadata hash disabled. It inherits the six conversion/preview methods
unmodified from OpenZeppelin Contracts commit
`932fddf69a699a9a80fd2396fd1a2ab91cdda123` (v5.0.0). Only `totalAssets`,
`totalSupply`, `_decimalsOffset` and `balanceOf` are overridden to read
controlled input slots. No constructor or live deployment is executed.

The Rust test `erc4626::oz_evm_oracle` executes those getters against 204
boundary and deterministic generated input vectors (1,224 getter calls).
The expected result comes from compiled Solidity, including checked
exponentiation/additions, `Math.mulDiv`'s modular-inverse path and checked
ceil increment. The interpreter implements only the bounded getter path;
unknown opcodes, bad jumps, unbound storage, stack errors and exhausted fuel
panic the test instead of counting as a Solidity revert. Its word arithmetic,
operand order and branching have direct sanity tests. This is independent
source execution evidence, not a full EVM implementation or qualification of
any deployed vault, runtime, getter capture or package.

Compiler-reported selectors are `07a2d13a` (`convertToAssets`), `c6e6f592`
(`convertToShares`), `4cdad506` (`previewRedeem`), `ef8b30f7`
(`previewDeposit`), `b3d7f6b9` (`previewMint`) and `0a28a477`
(`previewWithdraw`). Recognized arithmetic reverts are panic `0x11` and
`MathOverflowedMulDiv()` (`227bc153`).

Regenerate with the repository Rust toolchain and a local solc 0.8.20 binary:

```sh
rustc --edition 2021 conformance/tools/build_oz_oracle.rs -o /tmp/build-oz-oracle
/tmp/build-oz-oracle /absolute/path/to/solc-0.8.20 out/oz-oracle-FRESH
cmp out/oz-oracle-FRESH/build/Oracle.bin-runtime conformance/fixtures/oz-v5-oracle.bin-runtime
cargo test --locked --offline -p conformance erc4626::oz_evm_oracle
```

The Rust generator fetches only pinned GitHub sources, saves their checkout,
compiler hashes, selectors and artifacts to a **fresh** output directory and
never accesses RPC/Firehose/Substreams. The normal test uses only the checked-in
bytecode and existing host-only dependencies; it needs neither network nor solc.
Initial generation evidence is under `out/erc4626-oz-oracle-20260921-02/`;
the failed initial compiler attempt remains in `out/erc4626-oz-oracle-20260921/`.
